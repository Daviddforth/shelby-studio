# Projects

Shelby Studio includes project-oriented tooling for organizing and managing development work around Shelby storage and NFT workflows.

## Overview

Projects provide a way to group related work inside Shelby Studio.

A project can represent:

- An NFT collection
- A storage workflow
- An application integration
- A development experiment
- A structured set of metadata and assets

The Projects area is intended to provide a higher-level view than individual assets.

---

## Project Model

The basic relationship is:

```text
Project
   |
   +-- Assets
   |
   +-- Metadata
   |
   +-- Collections
   |
   +-- Storage
   |
   +-- Development Workflows
```
