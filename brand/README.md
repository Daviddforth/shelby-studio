# Shelby Studio brand assets

Original artwork for Shelby Studio.

| File | Use |
| --- | --- |
| `logo-mark.svg`, `logo-mark-512.png` | Logo mark (vector and PNG) |
| `profile-picture-800.png` | X / social profile picture (square, safe for circle crop) |
| `banner-x-1500x500.png`, `banner-x.svg` | X (Twitter) header banner |
| `share-image-1200x630.png`, `share-image.svg` | Link preview image (also used at `app/opengraph-image.png`) |

The app itself uses `public/branding/shelby-studio-logo.png` (sidebar and top bar),
and `app/icon.png`, `app/apple-icon.png` and `app/favicon.ico` for browser icons.
